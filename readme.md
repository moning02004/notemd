# note.md

마크다운으로 노트를 작성하고, 검색하고, 워크스페이스 단위로 공유하는 셀프호스팅 노트 애플리케이션.
FastAPI(백엔드) + Next.js(프론트엔드) + PostgreSQL + Meilisearch + Celery 구성이며, Docker Compose로 전체 스택 실행.

**1인 개발 개인 프로젝트** · 2025년 11월 ~ 2026년 8월 · 커밋 201개

## 무엇을 만들었나

개인 또는 소규모 팀이 직접 띄워 쓰는 노트 서비스.
"노트를 쓴다"는 기본 기능 위에, 실제 서비스에 필요한 주변 요소 — 저장 이력, 휴지통 만료 정책, 전문 검색,
공유 권한, 본문 암호화 — 를 직접 설계해 붙이는 데 초점을 둠.

| 항목 | 규모 |
|---|---|
| 백엔드 | Python 약 3,200줄, 도메인 모듈 7개, API 엔드포인트 41개 |
| 프론트엔드 | TypeScript/TSX 약 6,000줄 |
| 테스트 | 백엔드 API 테스트 31개 (in-memory SQLite) |
| DB | Alembic 마이그레이션 16개 |
| 인프라 | Docker Compose 서비스 7개 + GitHub Actions 이미지 배포 |

## 주요 기능

**노트 작성**
- Tiptap 기반 WYSIWYG 에디터 — 표, 체크리스트, 토글(접기/펼치기), 이미지 드래그&드롭 업로드
- 코드블록 14개 언어 하이라이팅과 복사 버튼, `>>` + 공백 입력 시 토글 블록으로 전환되는 입력 규칙 등 직접 구현한 확장
- 자동 저장 — 바뀐 필드만 골라 PATCH 전송, 본문·제목은 타이핑이 멈춘 뒤(500ms), 설정 변경은 즉시 저장
- 템플릿을 만들어 새 노트의 시작점으로 사용

**정리와 검색**
- 태그, 카드/리스트 보기 전환, 정렬, 20개 단위 페이지네이션
- Meilisearch 전문 검색 — 노트 저장·삭제·복구 시마다 색인 동기화, 검색 범위는 사용자 단위로 격리
- 휴지통(소프트 삭제)과 복구 — 사용자가 고른 보관 기간(15일 / 30일 / 보관 안 함)에 따라 매일 자정 Celery Beat가 만료분 영구 삭제

**이력 관리**
- 노트 스냅샷 저장·복원·삭제
- 스냅샷 생성 정책을 사용자가 선택 — 수동 / 하루 첫 편집 시 / 매 편집 시
- 공유 중인 노트는 정책과 무관하게 편집마다 스냅샷을 남겨 편집 이력 추적

**공유**
- 워크스페이스에 멤버와 노트를 묶어 공유, 멤버는 공유된 노트 편집 가능
- 공개 링크로 로그인 없이 열람, 노트별 비밀번호 설정 지원

**가져오기 / 내보내기**
- PDF(텍스트 추출), 마크다운, 코드 파일 업로드 → 노트로 변환 (코드 파일은 확장자에 맞는 코드블록으로 변환)
- 노트 1개는 `.md`, 여러 개는 zip으로 내려받기

**계정**
- 최초 가입자가 관리자, 이후 계정은 관리자가 발급하는 방식 (셀프호스팅 전제)
- 액세스 토큰 15분(헤더) + 리프레시 토큰 14일(HttpOnly 쿠키)

## 기술적으로 신경 쓴 부분

### 노트 본문 암호화 (봉투 암호화)

| 키 / 데이터 | 보관 위치 | 역할 |
|---|---|---|
| KEK | 환경변수 | DEK를 감싸는 마스터 키 |
| DEK | DB (KEK로 암호화된 상태) | 사용자별 데이터 키 |
| 암호문 | DB | DEK로 암호화한 노트 본문·노트 비밀번호 |

- 암호화·복호화 전 구간 AES-GCM 사용
- AAD에 사용자 식별자를 묶어, 다른 사용자의 암호문을 가져와 복호화하는 경로 차단
- 키 교체를 대비해 사용자마다 KEK 버전 기록
- 서버가 복호화하는 구조이므로 종단간 암호화(E2E)는 아님 — DB 유출 시 본문 보호가 목적

### 계층 분리와 자체 라이브러리

- 모듈 7개(note · tag · template · workspace · preference · search · user)를 각각 `domain / application / infrastructure / interfaces` 4계층으로 분리
- 반복되는 골격(베이스 모델, 설정 로더, 서비스·리포지토리 기반 클래스, 관리 커맨드)은 직접 만들어 PyPI에 공개한 [fastapi-clean-archi](https://github.com/moning02004/fastapi-clean-archi)로 분리
- 이 프로젝트가 그 라이브러리의 실사용처이며, 새 모듈은 관리 커맨드 한 줄로 4계층 골격 생성

### 토큰 재발급 경합 처리

- 401 수신 시 리프레시 후 원래 요청 재시도
- 여러 요청이 동시에 401을 받아도 진행 중인 재발급 요청을 공유해 호출은 한 번만 발생
- 토큰 없이 보낸 공개 노트 요청의 401은 재발급 대상에서 제외
